# 동네픽 — 프로젝트 3 학습용 SNS

소상공인이 가게 소식을 올리고 이웃이 검색·댓글·좋아요로 소통하는 로컬 웹 프로젝트입니다.

## 필요한 프로그램
- JDK 17 이상
- Node.js 20.19 이상 또는 22.12 이상 (npm 포함)
- 최초 실행 시 Maven과 npm 의존성을 받기 위한 인터넷 연결

## 실행 방법 (Windows PowerShell)
압축을 풀고 각각의 폴더에서 별도 터미널을 실행합니다.

터미널 1: 백엔드
```powershell
cd backend
.\mvnw.cmd spring-boot:run
```
백엔드가 8080 포트에서 시작할 때까지 기다립니다.

터미널 2: 프론트엔드
```powershell
cd frontend
npm install
npm run dev
```
브라우저에서 http://127.0.0.1:5173 을 엽니다. 터미널의 주소가 다르면 터미널에 표시된 주소를 사용하세요. 두 터미널을 실행 상태로 유지해야 합니다.

체험 계정: `demo@dongne.kr` / `demo1234` (빈 데이터베이스에서 처음 시작할 때 생성)

## 구현 기능
- 회원가입, 로그인/로그아웃, BCrypt 비밀번호 해시
- 가게 등록·수정 및 프로필 조회
- 게시물 작성·조회·검색·수정·삭제, 선택적 이미지 URL
- 댓글 등록·삭제, 좋아요 추가·취소
- 작성자별 변경 권한 확인, 관계형 데이터 외래키 및 좋아요 중복 제약
- 화면 크기에 따른 반응형 레이아웃

H2 데이터베이스 파일은 `backend/data/`에 생성되며 압축 파일에는 포함하지 않습니다. 이미지 파일 업로드가 아니라 이미지 URL을 사용합니다.

## 확인 방법
1. 체험 계정으로 로그인합니다.
2. 피드에서 가게 이름을 누르면 가게 프로필이 열립니다.
3. 소식 올리기에서 새 글을 작성하고 좋아요와 댓글을 확인합니다.
4. 다른 계정으로 로그인해 작성자의 글을 수정·삭제할 수 없는지 확인합니다.
5. 프론트엔드 `npm run build`, 백엔드 `./mvnw.cmd test`로 빌드를 점검합니다.

## 과제 진행 상태
이 코드는 새로 만든 Spring Boot REST + React 로컬 데모입니다. 기존 MVC 프로젝트를 전환한 이력이나 이전 UI는 없으므로 문항 3은 별도의 학습용 MVC 예제와 실제 화면 캡처를 만들어 비교해야 합니다. GitHub 협업 기록은 팀원이 실제로 브랜치에서 작업하고 커밋 및 병합하여 남겨야 합니다.

## 제한 사항
수업용 로컬 데모이며 CSRF 보호가 꺼져 있습니다. 공개 서비스에 배포하기 전에는 CSRF 방어, HTTPS, 인증·인가 강화, 비밀 정보 관리, 요청 제한, 운영 데이터베이스 및 입력·이미지 보안 검토가 필요합니다. 외부 공개용으로 사용하지 마세요.

## 발표 시연 순서
1. 처음 화면에서 가게 소식과 검색 기능을 보여 줍니다.
2. 체험 계정으로 로그인하고 가게 프로필을 확인합니다.
3. 소식을 하나 등록한 다음 좋아요와 댓글을 남깁니다.
4. 작성한 게시물을 수정하거나 삭제하고, 로그아웃합니다.

## 브랜치 연습
이 저장소의 기능별 브랜치는 단독 작업에서 버전 관리 흐름을 연습하기 위한 것입니다. 실제 팀원별 협업 이력으로 표시하지 않습니다.
